 Market Research and Competitor Analysis Using Microsoft Power BI

 Project Overview
This project analyzes company performance, product pricing, sales revenue, customer ratings, marketing expenses, regional performance, and monthly market trends using Microsoft Power BI.

The objective is to transform raw data into meaningful insights through interactive dashboards and data visualization to support business decision-making.

 Objectives
 Compare the performance of different companies.
 Analyze product prices, sales revenue, and customer ratings.
 Evaluate marketing expenses and business performance.
 Identify regional sales trends and monthly performance.
 Build interactive dashboards for business reporting.
 Practice data cleaning, data modeling, and DAX calculations.

 Tools and Technologies
 Microsoft Power BI
 Power Query
 DAX (Data Analysis Expressions)
 Microsoft Excel
 CSV Dataset

 Dataset Details
Total Records: 1,800
  Companies 6
 Products: 25
 Categories: 5
 Regions: 5
 Date Range: January 2024 – December 2025

**Note:** The dataset contains simulated data created for educational and portfolio purposes. The company names, sales, prices, ratings, and marketing expenses are fictional and do not represent verified real-world market information.

## Key Features
- Company performance comparison
- Sales and revenue analysis
- Product price and rating comparison
- Marketing expense analysis
- Regional performance analysis
- Monthly market trend analysis
- Interactive charts, KPI cards, and slicers
- Data transformation using Power Query
- Data modeling and DAX measures
